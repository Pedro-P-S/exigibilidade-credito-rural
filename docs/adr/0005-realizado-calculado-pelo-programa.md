# Realizado calculado pelo programa para o operacional; diretores veem o oficial

O valor oficial do Sisex também pode ter erro. Por isso o programa calcula o realizado a partir da base de operações (saldo diário de cada operação), com as mesmas regras da projeção, e o relatório operacional mostra calculado, oficial e diferença por código, para achar o erro de um ou de outro. O relatório dos diretores é outro arquivo e mostra só o oficial nos meses passados e a projeção nos futuros.
