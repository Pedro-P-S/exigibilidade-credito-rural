# Realizado calculado pelo programa, com o Sisex só ao lado

O valor oficial do Sisex também pode ter erro. Por isso o realizado é calculado pelo próprio programa a partir da base de operações, com as mesmas regras da projeção, e o valor do Sisex aparece ao lado com a diferença, como referência para achar o erro de um ou de outro. Usar o Sisex direto como realizado seria mais simples, mas esconderia os erros do oficial.
