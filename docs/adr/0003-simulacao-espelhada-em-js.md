# Simulação no HTML com cópia das fórmulas em JavaScript, conferida contra o Python

Os gestores precisam mudar parâmetros e ver o resultado na hora, num HTML aberto sem servidor. As fórmulas do Sisex e das premissas gerenciais (`com_parametros`, `dir_final`, `acum`, `aplicar`, `sisex`) existem em Python e numa cópia em JavaScript dentro do HTML. Ao abrir, o HTML recalcula com os parâmetros da rodada e mostra "CHECK simulação = Python" OK ou FALHOU. Toda mudança numa dessas funções tem de ser feita nas duas.
