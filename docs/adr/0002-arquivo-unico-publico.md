# Um arquivo Python só, sem dependências, entregue por um repositório público

O programa roda num computador de trabalho que não temos como acessar, sem instalar pacotes e com um assistente de IA só de chat. Por isso ele é um único `exigibilidade.py` só com a biblioteca padrão (o `openpyxl` só para ler `.xlsx` e o `pyodbc` só para ler o banco do trabalho), copiado pelo Raw do GitHub. O repositório é público: nada confidencial entra nele. Dados, nomes de sistemas, tabelas, pessoas e o conteúdo de reuniões ficam fora, e o `.gitignore` funciona como lista de permissão. Nomes de tabelas, colunas e a conexão do banco ficam no `consultas_banco.ini`, que só existe no computador do trabalho.
